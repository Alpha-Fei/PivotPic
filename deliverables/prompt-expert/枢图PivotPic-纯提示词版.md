## 功能规格

### FS-01 多目录监控

- 支持配置任意数量（软上限 32 个，超出时提示「最多支持 32 个监控目录」）的监控目录，逐个独立启停。
- 每个目录含四个独立配置项：

| 配置项 | 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| 启用监控 | `Enabled` | bool | true | 关闭后该目录完全不挂 Watcher |
| 包含子文件夹 | `IncludeSubdirectories` | bool | **true** | 开启时递归监控全部层级；关闭时只监控该目录第一层，子文件夹内的文件完全忽略 |
| 分辨率检查 | `ResolutionCheckEnabled` | bool | **false** | 关闭时不做任何尺寸判定，只执行旋转 |
| 阈值 | `Threshold` | double | **300** | 仅在分辨率检查开启时生效 |

- 文件筛选：只处理扩展名白名单内的文件，默认 `.jpg .jpeg .png .bmp .webp .tif .tiff`（扩展名比较不区分大小写）。运行时探测系统 WIC 编解码器，对不可用的格式在设置页置灰并标注「当前系统缺少该格式解码器」。
- 目录不存在时：先尝试创建（含中间层级）；创建失败则在卡片上标红「路径不可用」并跳过，不弹错误框、不中断其他目录。
- 目录被删除或重命名时：Watcher 触发 `Error` 事件后标记卡片为「已断开」，每 30 秒重试挂载一次，恢复后自动复位。
- 添加方式三种并存：点击虚线卡片弹出目录选择器、把文件夹从资源管理器拖入卡片列表区（`AllowDrop`，拖入时整块区域描边变强调色 + 8px 缩放反馈）、手动输入路径（支持粘贴）。
- **首次全量扫描（必须实现）**：仅靠文件系统事件无法处理目录中已存在的历史图片。因此新目录添加成功后、以及用户点击卡片上的「立即扫描」时，必须启动一次后台全量扫描：按 FS-01 的子文件夹开关决定递归深度，遍历白名单扩展名文件，逐个投递到 FS-08 队列。扫描期间卡片显示进度条与「已扫描 N / 共 M」，提供「取消」按钮；扫描任务可被暂停监控中断。同一目录的全量扫描与实时事件共用同一去重表，不得重复处理同一文件。
- 遍历时跳过 `FileAttributes.ReparsePoint` 的目录与文件（符号链接、junction），防止目录环路导致死循环遍历。
- 全量扫描为串行、可取消，每处理 50 个文件让出一次线程（`await Task.Yield()`），保证扫描期间界面操作不掉帧。

### FS-02 方向归一化与旋转（核心逻辑）

- 判定规则：`PixelWidth > PixelHeight` 即横版，顺时针旋转 90° 变成竖版；`PixelWidth <= PixelHeight`（竖版或正方形）一律跳过，不写入、不重编码。
- 幂等性说明：旋转一次后宽高互换，再次扫描必然落入 `Width < Height` 分支被跳过，方向判定本身天然幂等。
- **EXIF Orientation 必须先归一化再判定**，这是本功能最容易出错的一步，必须按以下顺序执行：
  1. 读 `BitmapFrame`，取 `PixelWidth` / `PixelHeight`；
  2. 读 EXIF 标签 `/app1/ifd/{ushort=274}`（Orientation）；读取失败按 `1` 处理；
  3. 当 Orientation ∈ {5,6,7,8} 时，先把「逻辑显示尺寸」换算为交换宽高后的值，再用逻辑尺寸做横竖判定 —— 否则会把一张「像素横向、EXIF 标记需旋转」的竖拍照片误判为横版并转错方向；
  4. 物理旋转时，旋转角度需与原始 Orientation 叠加计算，最终结果必须是视觉上正向的竖版。
- 写回策略（两档，由设置项 `RotationMode` 控制）：
  - `Physical`（默认）：物理旋转像素后重编码写回。JPEG 用 `QualityLevel = 95`；PNG / BMP / TIFF 走无损像素旋转；WEBP 依赖系统编解码器。
  - `ExifOnly`（高级选项，默认关闭）：只把 EXIF Orientation 改写为对应值、不重编码像素，零画质损失；此模式必须记录已处理指纹，否则同一文件会被反复命中。
- 元数据保留：写回时经 `BitmapMetadata.Clone()` 传递 EXIF / ICC / DPI 到新帧；把 Orientation 置为 1（`/app1/ifd/{ushort=274}` 写 `ushort 1`）。该写入可能抛 `NotSupportedException` 或「元数据不可写」，必须 try/catch 降级为「不写 Orientation，仅靠像素旋转保证视觉正确」并记 Warn 日志，禁止让异常冒泡。
- 文件写入安全（三步不可省）：
  1. 目标目录写临时文件 `{原名}.{8位随机}.tmp`；
  2. 用 `File.Replace(tmp, 原文件, 备份路径)` 原子替换；`File.Replace` 在跨卷或非 NTFS 场景失败时降级为「删除原文件 + `File.Move`」，并在日志中标明降级；
  3. 任一步失败：删除临时文件、保留原文件、记 Error 日志、该文件重试 2 次后放弃。
- 只读文件、被其他进程独占的文件、零字节文件、损坏文件：跳过并记 Warn 日志，不弹窗、不中断队列。
- 超大图保护：解码前只读文件头取尺寸，像素总数超过 `{MAX_PIXELS}`（默认 1.2 亿）直接跳过并记日志，防止 `OutOfMemoryException` 拖垮进程。
- 旋转方向由设置项 `RotateDirection` 控制，默认 `Clockwise`（顺时针），可切 `CounterClockwise`。

### FS-03 分辨率阈值巡检

- 每个目录独立开关，默认关闭；阈值默认 300；判定口径 `ThresholdMetric` 默认 `LongEdge`（长边像素），可选 `ShortEdge`（短边像素）/ `Megapixel`（总像素，单位万像素）/ `FileSizeKb`（文件体积 KB）。
- 命中条件：按所选口径取值**严格大于**阈值即告警；恰好等于阈值不告警。
- 告警三处同时呈现，全程不抢焦点、不打断用户当前操作：
  1. 右下角自绘 Toast 卡片：从右侧滑入，非模态、`ShowActivated = false`、5 秒自动淡出、鼠标悬停暂停计时、最多同屏堆叠 3 条，超出折叠为「另有 N 个文件超出阈值」，点击折叠条展开为列表窗；
  2. 托盘图标叠加红色角标（矢量渲染），ToolTip 显示未读告警数；
  3. 主界面「监控」页对应文件夹卡片显示告警计数徽标，点击进入过滤后的告警列表。
- 每条 Toast 与每个列表项提供「定位」按钮：执行 `explorer.exe /select,"{完整路径}"`，参数中的路径必须整体加双引号以兼容空格与逗号；`Process.Start` 抛异常时 Toast 改为提示「无法打开资源管理器」并记日志。
- 去重：以「完整路径 + 最后写入时间 + 命中尺寸」为键，24 小时内同一键不重复提醒。去重记录持久化到 `alert-history.json`，保留 7 天后自动清理。

### FS-04 系统托盘驻留

- 启动后默认只驻留托盘，不弹主窗口（首次运行例外：首次运行且无配置时显示主窗口并进入引导态）。
- 关闭主窗口的行为由 `CloseAction` 控制，默认 `MinimizeToTray`；设为退出时走完整退出流程。
- 托盘右键菜单（全部为矢量绘制的自绘菜单，不用系统原生 `ContextMenuStrip`）：打开主界面 / 暂停监控 / 恢复监控 / 设置 / 关于 / 退出。菜单项带图标槽位，键盘上下键可导航。
- 双击托盘图标显示并激活主窗口；单击仅显示 ToolTip。
- 托盘图标为矢量绘制：用 `DrawingVisual` + `RenderTargetBitmap` 按 16 / 20 / 24 / 32 / 48 / 256 六种尺寸渲染同一段 `StreamGeometry`，组装成多帧 `System.Drawing.Icon`（PNG 压缩帧写 ICO 头），随状态切换三种形态：空闲（单色描边）/ 监控中（强调色）/ 有告警（强调色 + 红点角标）。
- 退出流程：先停止全部 Watcher → 等待队列内任务完成或超时 3 秒 → 释放托盘图标 → `Application.Shutdown()`。禁止用 `Environment.Exit` 硬杀。

### FS-05 单实例互斥

- 用命名互斥量 `Local\{APP_NAME}.SingleInstance.{GUID}` 做首道判定。
- 已有实例时不得静默退出：新进程通过命名管道 `\\.\pipe\{APP_NAME}.Activate` 向旧实例发送 `ACTIVATE` 指令，旧实例收到后 `ShowWindow + SetForegroundWindow`（必要时 `AllowSetForegroundWindow`）把窗口拉到前台，新进程随即以退出码 0 结束。
- 管道连接失败（旧实例忙或已崩溃残留）：退化为仅 Mutex 判定，静默退出并写日志，不得弹出「程序已在运行」的模态框。
- 管道服务端用后台线程 + `WaitForConnectionAsync` + `CancellationToken`，杜绝在 UI 线程阻塞。

### FS-06 路径时间占位符

- 目录路径支持占位符，按**大小写不敏感**字典展开，示例基准时间 `2026-11-04 09:15:32`：

| 占位符 | 展开值 | 含义 |
|---|---|---|
| `{yyyy}` | 2026 | 四位年 |
| `{yy}` | 26 | 两位年 |
| `{mm}` 或 `{MM}` | 11 | 两位月（补零） |
| `{dd}` 或 `{DD}` | 04 | 两位日（补零） |
| `{hh}` 或 `{HH}` | 09 | 两位时（24 小时制） |
| `{mi}` | 15 | 两位分 |
| `{ss}` | 32 | 两位秒 |

- 关键规则：`{mm}` 一律解析为「月」，不解析为「分钟」；分钟只认 `{mi}`。这样 `{mm-dd}` 展开为 `11-04`，与本工具的既定用法一致。
- 单个 `M` / `d` 形式（`{m}` `{d}` `{h}`）展开为不补零值（11、4、9）。
- 支持环境变量展开：`%USERPROFILE%`、`%APPDATA%` 等在展开前先做 `Environment.ExpandEnvironmentVariables`。
- 未识别的 `{xxx}`：原样保留，并在设置页该输入框下方给出黄色行内提示「未识别占位符：{xxx}」，不得静默吞掉或报错。
- 实时性与跨零点：每次监控启动、每次配置保存、以及每天 00:00:10 的定时器各重解析一次路径；路径变化时先卸旧 Watcher 再挂新 Watcher，已处理指纹按目录隔离。解析后的目录不存在时按 FS-01 的创建规则处理。
- 设置页须实时显示「解析结果预览」一行灰字，随输入即时更新（300ms 防抖）。

### FS-07 配置持久化

- 存储位置 `%AppData%\{APP_NAME}\config.json`，UTF-8 无 BOM，`WriteIndented = true`，中文不转义。
- 写入采用「写 .tmp → 原子替换」，连续写入做 500ms 防抖，避免频繁落盘。
- 读取失败（JSON 损坏、字段缺失、类型不符）：把原文件重命名备份为 `config.broken.{yyyyMMddHHmmss}.json`，回退到默认配置并在界面顶部给出一次性提示条「配置文件损坏，已恢复默认设置」。
- 反序列化必须容错：`JsonSerializerOptions` 开 `PropertyNameCaseInsensitive`、`ReadCommentHandling = Skip`、`AllowTrailingCommas`；单个字段缺失不得导致整体回退。
- 提供「导出配置」「导入配置」两个按钮，导出为同名 json，导入前做 schema 校验，校验失败提示具体字段。

### FS-08 处理队列与稳定性检测

- 单条串行处理队列（`Channel<ProcessTask>` + 单消费者后台任务），并发度 1，避免多线程争抢磁盘与内存峰值。
- 文件稳定性检测：收到 `Created` / `Changed` / `Renamed` 事件后，不立即处理，投入延迟队列等待 400ms；随后连续两次采样（间隔 250ms）文件大小与最后写入时间均未变化，且能以 `FileShare.None` 独占打开，才判定写入完成并进入处理。
- 事件合并：同一路径在 1 秒内多次事件只保留一条任务（`ConcurrentDictionary<string, DateTime>` 去重）。
- 自触发抑制（关键）：每次程序自身写回文件前，先把该路径登记的「忽略指纹」（路径小写 + 文件长度 + 最后写入时间 ticks）放入 `IgnoreSet`，TTL 8 秒；Watcher 事件到达时先查 `IgnoreSet`，命中则丢弃该事件并移除指纹。此机制必须实现，否则旋转会触发无限循环。
- 队列可视化：底部状态条显示「队列 N · 处理中 {文件名}」；暂停监控时队列继续消费完毕但不接收新任务。

### FS-09 日志与可观测性

- 滚动日志 `%AppData%\{APP_NAME}\logs\app-{yyyyMMdd}.log`，单文件 5 MB 上限，保留最近 7 个文件。
- 每次处理记一行结构化日志：时间 / 级别 / 目录 / 文件名 / 原尺寸 / 动作（Rotated / SkippedVertical / SkippedSquare / Alert / Failed）/ 耗时 ms / 异常摘要。
- 界面「日志」页：虚拟化列表（`VirtualizingStackPanel`）、级别筛选（全部 / 信息 / 警告 / 错误）、关键字搜索、一键打开日志目录、导出当前筛选结果为 txt。
- 全局异常兜底：`DispatcherUnhandledException`、`AppDomain.UnhandledException`、`TaskScheduler.UnobservedTaskException` 三处捕获 → 写 Error 日志 → 托盘 Toast 提示「发生未处理异常，详情见日志」→ 标记 `Handled = true`。进程不得因单次异常退出。

### FS-10 全局主开关与开机自启

- 主界面顶部固定一条「总控条」：左侧状态灯（矢量圆点 + 呼吸微动效，仅在监控中呼吸）、「监控中 / 已暂停」文字、今日已处理 N 张与告警 M 条的等宽数字；右侧一枚胶囊主开关，关闭即全部目录暂停（Watcher 全部卸载、队列清空但不丢弃进行中的当前文件）。
- 总开关状态与各目录 `Enabled` 是两级关系：总开关关闭时，所有目录卡片进入 40% 透明度禁用态，但各自的 `Enabled` 值不被改写；总开关恢复后按各自 `Enabled` 还原。
- 开机自启：设置页提供「开机自动启动」开关（默认 `{LOGIN_START}` 为 false），实现方式为写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 键，值为 `"{exe 完整路径}" --tray`；关闭时删除该值。只允许写 HKCU，禁止写 HKLM，禁止请求管理员权限。
- 带 `--tray` 参数启动时强制不显示主窗口（覆盖「首次运行显示主窗口」规则），保证开机自启不打断用户。

## 视觉规格

### VS-01 设计语言：2026 几何极简

- 设计基调：几何极简（Geometric Minimalism）—— 以矩形、圆角、圆、等距网格为全部造型语汇；不使用渐变拟物、不使用投影贴图、不使用装饰性插画、不使用 emoji。
- 栅格：4pt 基线，常用间距 8 / 12 / 16 / 24 / 32。
- 圆角三档：窗口与浮层 20，卡片 16，控件 10，胶囊与徽标 999。
- 层级靠「底色差 + 1px 极淡描边 + 双层柔和阴影（y=1 blur=2 alpha .06；y=8 blur=24 alpha .10）」表达，不靠粗边框。
- 字重对比明确：标题 Semibold 600，正文 Regular 400，数字与路径用等宽字体（`Cascadia Mono`，回退 `Consolas`）。

### VS-03 图标系统（全矢量）

- 全部图标定义在 `Themes/Icons.xaml` 的 `ResourceDictionary` 中，统一 `StreamGeometry`，基于 24×24 视框、1.5px 描边、圆头圆角连接、`StrokeLineJoin = Round`。
- 图标通过 `Path` 的 `Data` 绑定 + `Stroke = {DynamicResource IconBrush}` 复用，颜色随语义状态切换，禁止为每种颜色复制几何。
- 必需图标清单（全部手写几何，不得从图标库复制 SVG 路径字符串来路不明的资源）：应用标记、文件夹、子文件夹树、分辨率、旋转、暂停、播放、设置、日志、信息、关闭、最小化、最大化、添加、删除、定位（靶心）、复制、搜索、筛选、主题切换、检查勾。
- 窗口图标与托盘图标同源：都由同一段几何在运行时渲染，保证品牌一致性。
- 禁止：`.ico` / `.png` / `.svg` 文件、`Segoe MDL2 Assets` / `Segoe Fluent Icons` 字体图标、emoji 充当图标、`Image` 控件承载图标。

### VS-04 动效

- 时长两档：状态切换 160ms，页面/布局切换 240ms。
- 缓动统一 `CubicEase(EaseOut)`；列表项进出用 `8px` 位移 + 透明度；卡片 `ScaleTransform` 0.98 → 1。
- 只对 `Opacity` / `TranslateTransform` / `ScaleTransform` 做动画，触发 GPU 合成；不对 `Width` / `Height` / `Margin` 做动画（会触发布局重排）。
- 开关滑块带 1.06 倍轻微回弹（240ms）；页面切换用 `Opacity + 12px` 位移交叉淡入。
- 禁止：弹跳循环动画、旋转 loading 贴纸、超过 300ms 的过渡、同时出现三个以上动效。

### VS-05 窗口与布局

- 无边框窗口（`WindowChrome`，`CaptionHeight = 0`），自绘 48px 标题栏，含矢量应用标记、标题、最小化、最大化/还原、关闭五个元素。
- 标题栏需支持：拖动移动、双击最大化、拖动到屏幕边缘贴合（Windows 11 Snap Layouts 需在 `WM_NCHITTEST` 中对最大化按钮区域返回 `HTMAXBUTTON`）。
- Windows 11 22H2 及以上：`DwmSetWindowAttribute` 设 `DWMWA_WINDOW_CORNER_PREFERENCE = 2`（圆角）与 `DWMWA_SYSTEMBACKDROP_TYPE = 2`（Mica）；调用失败或低版本系统降级为纯色底，不得抛异常。
- 默认尺寸 1000×680，最小 760×560，居中启动，记住上次位置与尺寸（越界时回正到主屏居中）。
- 布局：左侧 72px 竖向图标导航（矢量图标 + 选中态为 40×40 圆角 12 的强调色 12% 底 + 3px 左侧竖条），右侧内容区，底部 32px 状态条。
- 导航项：监控 / 设置 / 日志 / 关于。选中态滑动：用一个共享的 `TranslateTransform` 在项间位移 240ms 过渡，不做逐项淡入。
- 「监控」页自上而下三段：顶部 56px 总控条（状态灯 + 状态文字 + 今日统计 + 主开关）→ 中部卡片滚动区 → 底部沿用全局状态条。

### VS-06 组件规格

- 文件夹卡片（高度自适应，最小 112px）：首行路径（过长时中间省略，hover 显示完整路径 + 复制按钮）；次行占位符解析结果（12px 灰字）；第三行三个胶囊开关（包含子文件夹 / 分辨率检查 / 启用）；阈值输入仅当「分辨率检查」开启时展开（240ms 高度动画改用 `Opacity + TranslateY` 实现，规避高度动画）；右上角删除按钮（仅 hover 时淡入）。
- 卡片扫描态：全量扫描进行时，卡片底部出现 2px 细进度条（强调色，圆角）+ 「已扫描 N / 共 M」等宽小字 + 「取消」文字按钮；扫描完成后进度条淡出，短暂显示「本次处理 X 张」2 秒后消失。
- 状态灯：8px 圆点，监控中为强调色并做 2.4s 呼吸（`Opacity` 0.45↔1，`SineEase` 往复），暂停时转为次文字色静态；不用旋转或闪烁动画。
- 胶囊开关：36×20 轨道，16 直径滑块，关闭态轨道为描边色，开启态为强调色 + 滑块白色，`IsChecked` 变化伴随 240ms 位移与回弹。
- 添加目录按钮：卡片列表末尾的虚线描边卡片（1px dash），内含 `+` 几何与「添加监控目录」文字。
- Toast：宽 360，圆角 16，左侧 3px 强调色竖条（告警为红），标题 14 Semibold，正文 12 次文字，右下「定位」文字按钮 + 关闭叉。
- 数值输入：只允许数字，失焦时校验范围（阈值 1–100000），越界回退到上次合法值并红色描边 200ms。
- 全部控件重写 `ControlTemplate`，不保留任何默认 Aero2 样式残留（按钮、滚动条、输入框、下拉、开关、列表项均需自绘）。

### VS-07 三态齐备

- 空态：无监控目录时，内容区居中显示矢量几何插画（由 3 个几何图形组合而成）+ 「尚未添加监控目录」+ 主按钮。
- 加载态：启动读取配置期间显示骨架（卡片轮廓 + 微光扫过，1.2s 循环，`Opacity` 0.4↔1）。
- 错误态：目录不可用时卡片左侧 3px 红条 + 「路径不可用」胶囊标签 + 「重新指定」按钮。

### VS-08 高 DPI 与可访问性

- 支持 100%–250% 缩放，全部尺寸用与设备无关单位，图标为矢量天然适配；`PerMonitorV2` DPI 感知（app.manifest 声明）。
- 键盘可达：Tab 顺序符合视觉顺序，`Esc` 关闭浮层，`Ctrl+,` 打开设置，`Ctrl+F` 聚焦搜索。
- 对比度：正文与底色对比度不低于 4.5:1；不只靠颜色传达状态（告警同时有图标与文字）。
